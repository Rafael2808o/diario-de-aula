# Diário de Aula

Plataforma acadêmica com painel web, API REST documentada e aplicativo móvel Expo.

## Rodar localmente

```bash
npm install
npm run dev:api
npm run dev:web
```

- Web: `http://localhost:5173`
- API e Swagger: `http://localhost:3333/docs`

Para o app: `cd Mobile && npm start` e abra com Expo Go. A geração de APK é configurada por `Mobile/eas.json` e requer uma conta Expo.
